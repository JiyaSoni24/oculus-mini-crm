
# OCULUS – Mini CRM Dashboard

**See Beyond. Connect Better.**

OCULUS is a responsive Mini CRM Dashboard built to manage business leads through a modern, interactive interface.

### Features
- Add, edit and delete leads
- Search by name and email
- Filter leads by status
- Dashboard statistics
- Responsive cosmic-themed UI
- Browser data persistence

### Technologies
- HTML
- CSS
- JavaScript
- LocalStorage

### Run locally
Download the repository and open index.html in your browser.

### Data storage
This version uses browser LocalStorage. It does not currently include a server-side database or backend API.
